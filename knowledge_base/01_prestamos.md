# Préstamos COLUA MICOOPE
Fuente: https://www.coluarl.com.gt/index.php/productos/mi-prestamo
Actualizado: 2026-09-07

COLUA MICOOPE publica varias finalidades de crédito para sus asociados. Entre ellas se encuentran crédito productivo para comercio, servicios o manufactura; crédito de consumo para gastos personales, compra de vehículo o menaje de casa; crédito de vivienda para compra, construcción o remodelación de vivienda, adquisición de terreno o liberación de gravamen hipotecario; crédito agrícola para capital de trabajo, activos fijos, tierras, cultivos o crianza de animales; créditos con garantía de ahorros; y microcréditos grupales para mujeres emprendedoras.

## Requisitos generales publicados
Para solicitar un préstamo, la información pública de COLUA indica como requisitos generales: ser asociado de COLUA MICOOPE, presentar DPI original, presentar un recibo reciente de servicios como luz o teléfono y presentar constancia de ingresos. Dependiendo de la garantía pueden solicitarse documentos adicionales, por ejemplo escritura pública o registrada o un fiador que también cumpla los requisitos generales. La cooperativa puede solicitar requisitos adicionales según el caso.

## Alcance del chatbot
El chatbot puede orientar sobre productos, recopilar datos para una precalificación preliminar y registrar una solicitud para revisión de un asesor. No debe afirmar que un crédito está aprobado, rechazado o garantizado. La decisión final corresponde a personal autorizado y a las políticas crediticias vigentes de COLUA.
