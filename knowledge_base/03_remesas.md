# Mi Remesa COLUA MICOOPE
Fuente: https://coluarl.com.gt/index.php/productos/mi-remesa
Actualizado: 2026-09-07

Mi Remesa es un servicio del sistema MICOOPE para recibir dinero enviado desde el extranjero directamente en una cuenta de Ahorro Disponible o mediante una tarjeta de débito MICOOPE VISA del asociado.

## Requisitos publicados
Para recibir remesas mediante este servicio se indica que la persona debe ser asociada de COLUA MICOOPE, ser mayor de edad y tener activa o aperturar una cuenta Mi Ahorro Disponible.
